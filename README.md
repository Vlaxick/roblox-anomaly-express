# Anomaly Express

Roblox tycoon + survival + extraction game.

## Development workflow

1. Keep Luau source and project configuration in this repository.
2. Run `rojo serve` from the repository root.
3. Open the place in Roblox Studio and connect with the Rojo plugin.
4. Build maps and visual assets in Studio; implement game systems in `src`.
5. Test in Studio, then commit a small, working change to Git.

## Source layout

- `src/server` — authoritative game logic and data handling
- `src/client` — interface, camera, effects, and player input
- `src/shared` — configuration and modules used by both sides
- `docs` — design decisions and milestone descriptions

## Current playable base slice

Start a Play test after connecting Rojo. Each player receives one of six 80×76-stud
research plots on a 600×600-stud campus. The plot contains an open laboratory,
EyeFlower greenhouse, energy collector, reactor, and specimen storage. The flower
produces 5 energy every 5 seconds, up to 100 in the collector. Collect it with the
proximity prompt to move it to your wallet and gain XP.

Spend 80 energy on the reactor to double production, or 150 energy on storage to
double collector capacity. These upgrades are server-authoritative but currently
reset between sessions; data saving is a later milestone. The station and parked
train are visual foundations only—the five-minute expedition cycle is not active.

The shared `Theme` palette keeps world props and the responsive HUD consistent.
Most map geometry is generated by `WorldService` and `PlotService` at runtime so
the complete blockout stays in Git rather than requiring manual Studio edits.
